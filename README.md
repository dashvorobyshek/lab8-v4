## Описание выполнения заданий

### Средняя сложность №4

В `task4.py` реализована функция `calculate()`. Она поддерживает сложение,
вычитание, умножение и деление. Деление на ноль вызывает
`ZeroDivisionError`, неизвестная операция - `ValueError`.

Сначала написаны тесты для заготовки с `NotImplementedError`.
После реализации функции тот же набор тестов проверяет четыре операции
и два случая ошибок. Тесты находятся в `tests/test_task4.py`.

```bash
python -m pytest tests/test_task4.py -q
```

### Средняя сложность №6

Правила проверки хранятся в `.flake8`. Максимальная длина строки - 79 символов. Виртуальное окружение и каталоги сборки исключены из проверки.

```bash
python -m flake8 .
```

### Средняя сложность №10

В [mvc.md](mvc.md) описана архитектура MVC для приложения «Список книг».
В документе указаны обязанности модели, представления и контроллера,
а также порядок их взаимодействия при добавлении книги.

### Повышенная сложность №5

В `task5pov.py` реализован маршрут `POST /words/count`.
Запрос `{"text": "Раз два три"}` возвращает `{"count": 3}` и код `200`.
Пустой текст, строка из пробелов и запрос без поля `text` дают код `422`.

Тесты в `tests/test_task5pov.py` сначала проверяют заготовку, которая
возвращает код `501`. После добавления модели запроса и подсчёта слов
проверки проходят. Для отправки запросов используется `TestClient`.

```bash
python -m pytest tests/test_task5pov.py -q
```

Ручной запуск:

```bash
python -m uvicorn task5pov:app --port 8005
```

Страница Swagger доступна по адресу http://127.0.0.1:8005/docs.

### Повышенная сложность №9

Пакет `lab8_textutils` содержит функцию `normalize_spaces()`.
Она убирает пробельные символы по краям и заменяет их группы внутри
строки одним пробелом. Зависимости для работы самого пакета не нужны.

- Страница пакета: https://test.pypi.org/project/lab8-textutils-dvorobyeva-221341/
- Версия: `0.1.0`.

Установка и проверка:

```bash
python -m pip install --index-url https://test.pypi.org/simple/ --no-deps lab8-textutils-dvorobyeva-221341==0.1.0
python -c "from lab8_textutils import normalize_spaces; print(normalize_spaces('  Привет   мир  '))"
```

Ожидаемый вывод: `Привет мир`.
