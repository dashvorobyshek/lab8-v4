# Архитектура MVC приложения «Список книг»

Приложение запускается командой `python task10.py`.
Пользователь может показать список книг, добавить книгу или выйти.

## Компоненты

| Компонент | Файл | Обязанности |
|---|---|---|
| Model - `BookModel` | `book_model.py` | Хранит книги, проверяет название и цену, возвращает копию списка. |
| View - `BookView` | `book_view.py` | Показывает меню и список книг, получает ввод, выводит сообщения. |
| Controller - `BookController` | `book_controller.py` | Обрабатывает действия пользователя и связывает модель с представлением. |
| Точка входа | `task10.py` | Создаёт компоненты и запускает контроллер. |

## Добавление книги

1. Представление получает название и цену от пользователя.
2. Контроллер преобразует цену в целое число.
3. Модель проверяет непустое название и неотрицательную цену.
4. При успешной проверке модель добавляет книгу.
5. Контроллер передаёт представлению сообщение об успехе или ошибке.

## Просмотр списка

Контроллер получает список из модели и передаёт его представлению
для вывода. Модель возвращает копию, чтобы изменение полученного списка
не влияло на её внутренние данные.

## Хранение данных и тестирование

При запуске список пустой. Книги хранятся в памяти до выхода из программы.

Модель проверяется тестами из `tests/test_book_model.py`.
Тесты вызывают её методы напрямую, без ввода с клавиатуры
и вывода в консоль.
