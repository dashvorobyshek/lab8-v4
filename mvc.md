# Архитектура MVC приложения «Список книг»

Приложение показывает список книг и позволяет добавить книгу по названию
и цене. Работа делится между моделью, представлением и контроллером.

| Компонент | За что отвечает |
|---|---|
| Model - модель | Хранит сведения о книгах, проверяет название и цену, добавляет записи и читает их из базы. |
| View - представление | Показывает форму, список книг и сообщения об ошибках. |
| Controller - контроллер | Принимает данные формы, вызывает модель и выбирает, что показать пользователю. |

## Что происходит при добавлении книги

1. Пользователь вводит название и цену в форме и нажимает «Добавить».
2. Контроллер передаёт данные модели.
3. Модель проверяет данные и сохраняет книгу. Если данные неверны,
   модель сообщает об ошибке.
4. Контроллер передаёт представлению обновлённый список или сообщение
   об ошибке. Представление показывает результат.

Разделение позволяет, например, заменить консольный вывод веб-страницей
и продолжить использовать ту же модель книг.
